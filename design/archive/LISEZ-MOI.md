# Archive des données de design (2026-11-09)

Ces fichiers viennent de l'époque où le catalogue de SOREAL IDLE vivait dans des Google Sheets : des scripts ponctuels de `design/` (`build-idle-*.mjs`) les produisaient à partir du miroir du wiki NGU Idle, puis des scripts `push-idle-*.mjs` les envoyaient dans la feuille de production. Le catalogue de production est aujourd'hui dans le classeur SQLite du moteur (et sa graine `desktop/graine/catalogue.json`) ; plus aucun fichier de `cloudflare/src`, `cloudflare/tests`, `cloudflare/tools`, `desktop/*.mjs` ni `desktop/src` ne les lit (vérifié par grep), donc ils sont conservés ici sans être supprimés. Les scripts `build-*`/`push-*` de `design/` pointent vers ce dossier. `ngu-boss-names-fr.json` est l'ancienne liste des noms de boss, remplacée par `design/catalogue/boss.json` (source unique) ; elle reste ici comme référence « avant » du test `idle-catalogue-boss-unique-v1`. Rien de ce dossier ne doit être relu par le jeu. Les mobs du miroir wiki absents du jeu sont listés dans `MOBS-A-VERIFIER.md`.
