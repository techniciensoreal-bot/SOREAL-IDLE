# Glossaire de traduction (SOREAL IDLE, 2026-10-03)

Traduire de l'anglais vers le français (tutoiement quand le texte s'adresse au joueur : « tu », « ton »). Garder le ton humoristique de l'original. NE JAMAIS toucher aux nombres, pourcentages, symboles grecs (α β δ…), « x2 », « 1E10 » : ils restent identiques, au même endroit.

- Energy → Énergie ; Magic → Magie ; Resource 3 / R3 → Ressource 3
- Power → Puissance ; Toughness → Endurance ; Cap → Plafond ; Bars / Bar → Barres / Barre ; Speed → Vitesse
- Attack → Attaque ; Defense → Défense ; Adventure → Aventure ; Boss → Boss ; Rebirth → Renaissance
- Gold → Or ; EXP → EXP ; AP → AP ; PP → PP ; QP → QP ; Drop Chance → Chance de drop ; drops → butin
- Perk → Atout ; Quirk → Manie ; Wish → Souhait ; Hack → Piratage ; Card → Carte ; Digger → Mineur ; Beard → Barbe
- Boost → Boost ; Potion → Potion ; Fruit → Fruit ; Augment → Augment ; Upgrade → Amélioration
- Garder tels quels : NGU, Wandoos, Yggdrasil, ITOPOD, MacGuffin, Wandoos 98, Time Machine → Time Machine, Blood Magic → Magie du sang, Money Pit → Puits d'argent, Beast, Walderp, Looty
- Noms propres de personnages (Jake, UUG, Icarus Proudbottom…) : gardés ; jeux de mots : adaptés si possible, sinon gardés.
- Chaque traduction d'un NOM doit rester courte et UNIQUE (deux noms anglais différents ne donnent jamais le même nom français).
