# Audit code du jeu (build 1260) contre moteur SOREAL : groupe « aventure »

Date : 2026-11-16. Lecture seule : l'IL de `Assembly-CSharp.dll` (outils `m.mjs`, `d.mjs`, `g.mjs`) a été comparé à `cloudflare/src/*.js` et aux modules client qui reproduisent des règles de combat (`cloudflare/public/modules/ui-aventure-1-v1.js`, `ui-combat-2-v1.js`, `mobs-types-v1.js`). Aucun fichier du dépôt n'a été modifié, sauf ce rapport.

Méthode (important pour la confiance) : plutôt que de lire à l'oeil, j'ai écrit des extracteurs jetables (dans le dossier scratchpad) qui parsent l'IL en données (table d'ennemis `createEnemyTable`, table d'objets `ItemNameDesc.constructItemInfo` : 515 objets, tables de butin `LootDrop::zone0Drop..zone45Drop`) puis comparent champ par champ avec le moteur SOREAL (`IDLE_ADVENTURE_MOB_BESTIARY_V1`, `IDLE_ADVENTURE_ITEM_CATALOG_V1`, `IDLE_ADVENTURE_ZONE_LOOT_PROFILE_V2`, `ZONE_GOLD_RANGES_V1`, `ZONE_BOSS_EXP_CHANCE_V1`). Les comparaisons de nombres tolèrent 2e-6 en relatif (valeurs float32 du jeu). Une valeur est dite ÉCART seulement quand les deux côtés ont été lus.

Conventions : CONFORME / ÉCART / ABSENT (le jeu fait, SOREAL non) / NON VÉRIFIÉ.

## 0. Constat d'ensemble

- Les DONNÉES (ennemis par zone, boss, taux de butin, stats d'objets) sont presque toutes déjà alignées sur le jeu : 31 zones x ~8 ennemis, 406 objets d'équipement, 32 zones de butin. Les écarts trouvés sont ponctuels (liste section 2).
- Le MODÈLE DE COMBAT est structurellement différent (choix SOREAL déjà inscrits au registre `constantes-soreal-v1.json`) : le jeu simule en temps réel avec des minuteries, SOREAL résout en barres de vie par coup (client) ou analytiquement (hors ligne). Le jeu n'a PAS de farm hors ligne de zone d'Aventure (voir 1.H) : cette fonction SOREAL n'a aucun équivalent dans le code du jeu.
- Le jeu ne donne ni Or ni EXP "par ennemi" au sens de la maquette SOREAL : l'Or est `arg x Range(4,5) x totalGoldbonus` (donc plage `[4a,5a]`), l'EXP de zone n'existe que sur les boss (1 jet par kill de boss, quantité fixe).
